# Electoral Analytics Explorer

A full-stack data analytics project investigating the relationship between campaign finance and electoral performance in U.S. elections.

## Current Stack

- React
- D3.js
- Python
- FastAPI
- pandas
- NumPy
- SQLite

## Research Question

How is campaign money associated with electoral performance in U.S. elections, and under what conditions is that relationship strongest?

## Status

Initial React frontend and FastAPI backend are connected and running.
